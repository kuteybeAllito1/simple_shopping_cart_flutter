# 🛒 Simple Shopping Cart App – Flutter + Provider

A simple and clean Flutter application that demonstrates the core features of a shopping cart, built with **Provider** for efficient state management.

![Made with Flutter](https://img.shields.io/badge/Made%20with-Flutter-blue?logo=flutter)
![State Management](https://img.shields.io/badge/State%20Management-Provider-blueviolet)

---

## ✨ Features

✅ **Product Display Page**  
Display a list of available products for users to browse.

➕ **Add to Cart**  
Add selected products to the cart with one tap.

➖ **Remove from Cart**  
Easily remove individual items from the cart.

🧮 **Total Price Calculation**  
Automatically calculates the total price of all items added to the cart.

🗑️ **Clear Cart**  
Clear all products from the cart at once.

🔄 **State Management using Provider**  
Utilizes the Provider package to manage and update the cart state reactively across the app.

---

## 🧰 Technologies Used

- **Flutter** – UI Toolkit  
- **Dart** – Programming Language  
- **Provider** – For state management
